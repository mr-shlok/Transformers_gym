## 🌟 Overview

**Transformers Gym** is a production-ready, premium cinematic web experience engineered for elite fitness brands. Combining state-of-the-art web technologies with an Awwwards-winning design aesthetic, this website delivers immersive scroll-based storytelling, interactive anti-gravity physics animations, and high-fidelity product & facility showcases.

---

## 🔥 Key Highlights & Features

- **🎨 Immersive Cinematic Hero:** Featuring custom HTML5 Canvas interactive particle and anti-gravity floating barbell/dumbbells animation responsive to user interactions.
- **✨ Kinetic Typography & Parallax:** Fluid text animations, depth-layered parallax scrolling, and background outline text that dynamically engages visitors.
- **⚡ Elite Facility & Services Showcase:** Dark luxury theme highlighting personal training, strength zones, cardio decks, and luxury amenities.
- **🛍️ Premium Product Showcase:** Interactive feature highlights for premium gym apparel and supplements.
- **📱 Fully Responsive & Optimized:** Lightning-fast static export compatibility with flawless mobile navigation and smooth micro-interactions.

---

## 🛠️ Technology Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion & Vanilla HTML5 Canvas
- **Deployment:** Vercel

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/mr-shlok/Transformers_gym.git
cd gym
```

### 2. Install dependencies
```bash
npm install
# or
yarn install
# or
pnpm install
```

### 3. Run the development server
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the live local build.
